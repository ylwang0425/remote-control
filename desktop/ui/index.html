手机能做什么

手机通过中继只能调用这套固定操作：看会话列表（sessions.list）、读某条会话的消息（session.read）、发一条消息（session.send）、停止正在跑的会话（session.stop）、回答会话里的提问（session.answer）、批准权限请求（session.approve）、列模型（models.list）、新建会话（session.create）。除此之外没有别的入口。其中每一项都要这台电脑如实上报了对应能力才会在手机上可用；没上报的操作不会显示成按钮，也不会假装成功。

Codex 的真实限制

Codex 走的是本机 app-tools 管道，能力有限，以下三件事如实不可用：

  • 停止：管道的工具目录里没有 interrupt / cancel / stop 之类的接口，所以上报 stop:codex = false，手机上不会出现 Codex 会话的停止按钮，也不会假报成功。
  • 回答提问：这条通道没有把答案交回原生提问调用的入口，所以上报 session.answer:codex = false。
  • 批准权限：Codex 的 app-tools 管道没有权限批准这类交互面，所以上报 session.approve:codex = false。

DSH 那边这些能力是单独判定的，以本页「能力」一行的实际显示为准，并以中继原样透传的能力位为准。其它没测到的能力位一律按 false 上报，页面不会把「没测过」说成「可以」。

这个页面做不到什么

没有 shell、没有命令框、没有文件浏览器，也没有绕开已上报能力去触碰会话的通道。WorkBuddy UIA 只是这台电脑上的显式 opt-in 配置，不会改变其他电脑或账号的权限。这里的每一个写操作都需要只有本页面能读到的令牌（CSRF）。
